# 银发安全出游微信小程序

这是现有 FastAPI Backend 的原生微信小程序客户端，不包含 Safety、freshness、风险或认证业务逻辑。

## 本地与真机运行配置

1. 在微信开发者工具中导入本目录。
2. 在 `config.js` 中把 `apiBaseUrl` 改为可访问的 Backend `/api/v1` 地址（Demo 账号已统一在 `config.js` 的 `demo` 字段中维护）。
3. Backend 启动并存在 active trip 后，进入老人页点击“开启定位守护”；家属页可查看地图与安全状态。

### 微信开发者工具关闭域名校验方法

本地开发与联调通常使用 HTTP（如 `http://127.0.0.1:8000/api/v1`），微信开发者工具默认会拦截非 HTTPS 与未备案域名请求，可通过以下方式关闭校验：

- **方法一（界面操作）**：在微信开发者工具右上角点击 **「详情」** -> 切换到 **「本地设置」** 面板 -> 勾选 **「不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书」**。
- **方法二（项目配置）**：本项目已在 `project.config.json` 的 `setting` 下配置 `"urlCheck": false"`，导入工具后会自动生效。

### 微信真机环境配置（真机需要 HTTPS）

微信真机客户端（真机预览、真机调试、体验版及正式发布）具有严格的安全限制：

1. **强制要求 HTTPS**：
   - 真机网络请求（`wx.request`、`wx.uploadFile` 等）**必须使用安全的 HTTPS 协议**，且必须具备合规有效的 TLS 证书。
   - 微信真机**不允许直接请求 `localhost` 或 `127.0.0.1`**。
2. **配置 request 合法域名**：
   - 登录 [微信公众平台](https://mp.weixin.qq.com/) 后台，进入 **「开发」->「开发管理」->「开发设置」->「服务器域名」**。
   - 在 **`request 合法域名`** 中添加 Backend API 所在的公网 HTTPS 域名（例如 `https://api.yourdomain.com`）。
   - 将 `config.js` 中的 `apiBaseUrl` 修改为已配置的 HTTPS 地址。
3. **局域网真机临时联调（仅限开发阶段临时使用）**：
   - 若在开发阶段手机与电脑连接同一局域网 Wi-Fi，且希望临时直连电脑内网 IP：
   - 在手机端打开小程序预览版后，点击右上角 **「···」** 胶囊菜单 -> 选择 **「开发调试」** -> 点击 **「打开调试」**。
   - 打开调试后小程序会重新加载，此时真机客户端将放行未配置域名的局域网 HTTP 请求（如 `http://192.168.x.x:8000/api/v1`）。但正式演示与生产环境必须部署 HTTPS 并配置合法域名。

定位不会随页面加载、登录恢复或下拉刷新自动启动。页面隐藏、卸载或下拉刷新时会停止并回到 `IDLE`。若定位权限被拒绝将进入 `PERMISSION_DENIED` 状态并停止轮询，可点击“打开设置”通过 `wx.openSetting` 重新授权。
