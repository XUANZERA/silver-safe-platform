# 银龄安全系统志愿者测试版本总体设计

## 1. 系统架构


```
微信小程序

老人端
 |
 |
Backend API
 |
 |
数据库


家属端
```

---

# 2. 模块划分


## 小程序端

负责：

- 用户交互
- 定位采集
- 数据展示


不负责：

- 风险计算
- 新鲜度判断


---

## Backend

负责：

- 用户认证
- 权限控制
- Trip管理
- Location存储
- Safety状态计算


---

## Database

负责：

保存：

- 用户
- 老人信息
- 家属关系
- 出游任务
- 定位记录


---

# 3. 数据流设计


## 老人定位流程


```
用户点击开启定位

↓

微信定位API

↓

小程序上传WGS84坐标

↓

Backend保存

↓

生成安全视图

```


---

## 家属查看流程


```
家属登录

↓

请求Safety View

↓

Backend返回状态

↓

小程序展示

```
