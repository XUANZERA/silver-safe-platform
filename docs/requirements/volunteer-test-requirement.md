# 银龄安全系统志愿者测试版本需求分析

## 1. 项目背景

银龄安全系统旨在帮助老年人独立出行过程中，通过位置采集、安全状态分析以及家属协同查看，提高老年人出行安全。

当前阶段目标不是正式商业部署，而是构建一个可供志愿者体验和反馈的小规模测试版本。


## 2. 测试阶段目标

本阶段目标：

1. 验证微信小程序完整用户流程。
2. 验证老人定位数据采集链路。
3. 验证家属查看安全状态能力。
4. 收集真实用户体验反馈。


## 3. 用户角色

### 老人用户

功能：

- 登录系统
- 查看今日出游任务
- 开启定位守护
- 查看当前定位状态


### 家属用户

功能：

- 登录系统
- 查看绑定老人信息
- 查看老人当前位置
- 查看安全状态


## 4. 功能需求

## FR-001 用户登录

系统应支持测试用户登录。

输入：

- 用户名
- 密码


输出：

- 登录成功
- 用户角色信息


---

## FR-002 老人定位

老人用户可以主动开启定位服务。

要求：

- 必须经过用户授权
- 使用微信定位接口
- 上传位置数据到 Backend


禁止：

- 后台偷偷启动定位
- 客户端计算风险


---

## FR-003 家属查看

家属用户可以查看：

- 老人当前位置
- 定位更新时间
- 安全状态


所有状态由 Backend 提供。


---

## FR-004 用户反馈

用户可以通过微信反馈入口提交体验问题。


---

# 5. 非功能需求

## 数据安全

要求：

- 测试数据库独立
- 不使用真实个人信息
- 不泄露测试密码


## 可复现性

任何志愿者按照测试指南均可以完成测试流程。


## 稳定性

异常情况下：

- 网络失败需要提示
- 权限拒绝需要提示


# 6. 验收标准

完成以下流程：

老人：

登录
→ 查看任务
→ 开启定位


家属：

登录
→ 查看老人位置


测试通过。
