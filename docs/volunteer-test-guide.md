# 志愿者测试使用说明

本版本仅用于志愿者体验。测试账号和密码由测试管理员单独提供，请勿转发；请勿在测试中填写真实健康信息或其他无关个人信息。

## 老人端

1. 打开小程序，进入“老人定位守护”。
2. 输入测试管理员提供的老人账号和密码。
3. 查看“今日任务”。
4. 点击“开启定位守护”，并允许微信获取位置信息。
5. 页面显示“定位守护中”后，可按测试安排携带手机移动。
6. 测试完成后点击“停止定位守护”，再点击“退出”。

定位只会在主动点击“开启定位守护”后运行；离开页面或刷新页面会停止。

## 家属端

1. 进入“家属安全地图”。
2. 输入测试管理员提供的家属账号和密码。
3. 查看安全状态、定位状态、更新时间和地图上的最近位置。
4. 需要获取最新信息时，点击“刷新安全信息”。
5. 查看完成后点击“退出”。

页面展示的安全状态和定位状态均由服务端返回，小程序不会自行判断风险。

## 问题与反馈

页面底部提供“提交反馈”入口，可反馈使用困难、功能异常和改进建议。出现网络异常时请稍后重试；定位权限被拒绝时，点击“打开设置”并允许位置信息后重新开启。
